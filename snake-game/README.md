# Snake Game

A standalone mobile-friendly browser snake game with touch and swipe controls.

## Features

- Touch/swipe controls for mobile devices
- Keyboard arrow key controls for desktop
- Score tracking with high score persistence
- Responsive layout that adapts to phone screens
- Increasing difficulty as score increases
- Clean UI matching the project's navy and light blue color scheme

## How to Play

1. Open `index.html` in any modern web browser
2. Click "Start Game" to begin
3. On mobile: swipe in any direction to control the snake
4. On desktop: use arrow keys or WASD to control the snake
5. Eat the orange food to grow and increase your score
6. Avoid hitting the walls or yourself

## Technical Details

- Self-contained single HTML file with embedded CSS and JavaScript
- No external dependencies
- Uses HTML5 Canvas for rendering
- LocalStorage for high score persistence
- Touch event handling for swipe gestures
- Responsive design with CSS media queries
